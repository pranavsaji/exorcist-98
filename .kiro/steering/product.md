# Product: Exorcist 98

- Exorcist 98 is the 1990s desktop antivirus, resurrected to protect AI coding agents.
- Users: developers and teams who use coding agents (Kiro, Claude Code, Cursor) and MCP servers.
- Core jobs: Full System Scan of a repo, Virus Definitions (signatures plus LLM heuristics), Real-Time Shield (MCP firewall), Quarantine Vault.
- Hackathon: Kiroween 2026, Resurrection category. Deadline Dec 4, 2026, 2:00 pm Pacific.
- Judging: Potential Impact, Technological Implementation, Design, Innovation, Presentation, 20% each.
- Every finding must show the file, line, the exact quoted span, severity, threat class and a fix.
- The golden path (scan the Haunted Repo, then block a rug-pulled MCP tool live) must never break.
