# UI direction: haunted retro desktop

- An original late-90s desktop look of our own design: beveled windows, title bars, a taskbar, pixel icons. No real operating system or antivirus brand assets.
- Scan window: green-on-black log, a progress bar that glitches ("possessed") when a threat is found.
- Severity shown as an "infection level" with text labels; color is never the only signal.
- Every finding is clickable down to the exact line and quoted span.
- Sound effects are original or licensed, muted by default, with a toggle.
- Accessible: keyboard navigation, focus rings, screen-reader labels, WCAG AA contrast.
- Plain language first, security terms second ("This file hides instructions for your AI" before "Prompt injection, EX-001").
